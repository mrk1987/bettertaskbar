## Claude Code Usage Monitor

BetterTaskbar adapts provider polling code and dashboard UI styling from
[Claude Code Usage Monitor](https://github.com/CodeZeno/Claude-Code-Usage-Monitor)
by Code Zeno Pty Ltd, pinned to `a2b2b31ba45dea921a36bb8002309f39c4b11f26`.
The provider subset is in `widgets/vendor/codezeno-usage-core`.
Local changes are described in its `PATCH.md`.

The BetterTaskbar dashboard and per-widget theme renderer/editor use their own
application model. Usage Monitor theme files are not directly interchangeable
with BetterTaskbar theme files.
